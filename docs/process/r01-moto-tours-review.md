# R-01: обзор конструктора moto.tours по скриншотам

Дата: 2026-10-20. Источник: 3 скриншота конструктора v2.0. Только изучение функций, без копирования (ADR-0003).

## Подтверждено
**Карта и маршрут**
- Базовая карта: **Яндекс Карты** (на карте логотип и «© Яндекс»), есть слой «Пробки», выбор слоёв, поиск, геолокация, линейка, полный экран.
- Поля: «Откуда», «Куда», «Стартуем» (по умолчанию сегодняшняя дата), переключатель «Маршрут с возвратом».
- Промежуточные точки: поле «Через», кнопки «+» и «−», ручка перетаскивания порядка, ссылка «Все точки».
- Кнопка «Пересчитать маршрут»; результаты показываются плитками, до расчёта они пустые (спиннеры).
- Иконка в разделе «Настройка маршрута» изображает автомобиль, а не мотоцикл.

**Мото-параметры**
- Скорости по четырём классам дорог: автомагистраль 150, магистраль 110, региональная 90, территориальная 60 км/ч (значения по умолчанию, у каждого есть подсказка).
- Топливо: объём двигателя 600, расход 6, объём бака 70 (по умолчанию; единицы не подписаны, значение бака выглядит странно для мотоцикла).
- Разделение маршрута: переключатели «по промежуточным точкам», «по часам», «по километрам».

**Слои карты** (вкладка «Настройка карты»)
- Отдых: мотодома, байкпост, отель, кемпинг.
- Контакты: мотобратья, сервисы, АЗС, ответственные по мотопаспортам.
- Заехать: достопримечательность (включена по умолчанию), пляж, источник.

**Панель действий** (4 иконки): очистить, копировать, печать, скачать.
**Прочее:** плавающая кнопка Telegram; блоки погоды и восхода/заката.

## Не найдено в настройках
- Режим извилистых дорог.
- Избегание грунта, платных дорог, магистралей.
- Выбор профиля транспорта (по иконке маршрут строится как автомобильный; не подтверждено).

## Нужно проверить (3 иконки на панели)
- «Копировать»: ссылка на маршрут, копия параметров или что-то иное?
- «Скачать»: какой формат (GPX, KML, PDF)?
- Остаётся ли маршрут после перезагрузки страницы без входа?

## Выводы для нас
1. Наши заявленные дифференциаторы подтверждены: у конкурента нет извилистого режима и избеганий.
2. Топливо и скорости сделаны как простые поля: мы можем дать пресеты по моделям мотоциклов и проверку реалистичности значений (бак 70 л, расход 6 при двигателе 600 и т.д.).
3. Для нового пользователя результат пуст, пока он не нажмёт расчёт. У нас стоит показывать пример или быстрый старт.
4. Карта на Яндекс Картах: см. ADR-0004 (выбор провайдера карт и маршрутизации).
