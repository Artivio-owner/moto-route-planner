# Спецификация: бюджет поездки

Дата: 2026-10-20. Статус: черновик, приоритет P1 (топливо и стоимость топлива входят в P0-4).

## Как это устроено у конкурента (со слов владельца продукта)
Отдельный блок «Расширенное бюджетирование»:
- Сколько человек в дороге: 1 или 2.
- Класс отелей: 3, 4 или 5 звёзд. От него зависит цена ночёвки, например 600 / 1000 / 1500 ₽ на человека (цифры приведены как пример).
- Расчёт еды по дням, тоже по звёздам и с примерно таким же средним чеком.
- Опция «кофе на заправках».
- Итоговая сумма.
На странице также видны пресеты 1–5 и выбор топлива 92/95/100.

## Что в этом слабое (возможности для нас)
1. **Цена «за человека» некорректна для жилья.** Отели считаются за номер: вдвоём в одном номере цена ночёвки почти не удваивается. У конкурента цена зависит от числа людей линейно.
2. **Фиксированные цены без региона и сезона.** Ночь в Сочи в августе и в Вологде в ноябре стоят по-разному.
3. **Звёзды, а не реальные цены.** Нет возможности ввести свою цену или выбрать «кемпинг / палатка», что для мотопутешественников типичный вариант.
4. **Нет связи с маршрутом.** Число ночей и еды должно считаться из разбивки по дням, а кофе на заправках из числа заправок.

## Наша модель
```
Бюджет = Топливо + Жильё + Еда + Кофе на заправках + Прочее
```
| Статья | Формула | Источник параметров |
|---|---|---|
| Топливо | литры по маршруту × число мотоциклов × цена за литр выбранной марки | Расход, бак, цена (пользователь; значения по умолчанию редактируемые) |
| Жильё | число ночей × число номеров × цена номера | Ночи из разбивки по дням; тип жилья: отель 3/4/5★, гостевой дом, кемпинг, свой вариант |
| Еда | число дней × число людей × средний чек | Три уровня (эконом / средний / высокий), редактируются |
| Кофе | число заправок × число людей × цена кофе | Число заправок из расчёта топлива; переключатель |
| Прочее | платные дороги, паромы, резерв на ремонт | Вручную; резерв в процентах |

Правила:
- Число номеров по умолчанию: 1 при двух людях, пользователь может выбрать 2.
- Число ночей берётся из разбивки по дням ([08-day-split-spec.md](08-day-split-spec.md)): число пунктов ночёвки, то есть дни пути минус 1, плюс дневки; ночь в конечной точке добавляется переключателем.
- Все цены по умолчанию помечены как ориентировочные, пользователь видит и может изменить каждую.
- Региональный коэффициент и сезонность: P2, источник цен нужно найти (см. открытые вопросы).

## Критерии приёмки (P1)
- Given маршрут на 3 дня и 2 человека When выбираю отель 4★ и 1 номер Then сумма жилья равна цене одного номера за 2 ночи, а не за двоих.
- Given включён «кофе на заправках» When маршрут требует 5 заправок Then в бюджете появляется 5 × людей × цена кофе.
- Given меняю любую цену вручную When пересчитываю Then итог обновляется, а изменённое значение помечено.
- Given маршрут в один день When считаю бюджет Then жильё равно 0, еда за 1 день.
- Итог показывается как итого и в разбивке по статьям; печать и шаринг содержат бюджет.
