# Конкурентный бриф

> Дата: 20.10.2026. Функции moto.tours определены по структуре страницы, а не тестированием вживую. Часть строк проверена по скриншотам 20.10.2026, см. [process/r01-moto-tours-review.md](process/r01-moto-tours-review.md).

## Продукты
| Продукт | Позиционирование | Заметки |
|---|---|---|
| moto.tours / Конструктор маршрутов v2.0 | Конструктор поездки внутри мотопортала и интернет-магазина | Скорости по классам дорог, топливо, бюджет, дни, мото-POI, погода |
| Calimoto | Извилистые маршруты и навигация | Сильные POI на карте, лимиты скорости с 2024 |
| Kurviger | Гибкий планировщик | Режимы маршрутизации, индивидуальные избегания; сложен для новичков |
| REVER | Сообщество и трекинг | Подписка PRO |
| Scenic | Навигация «для перчаток» | Веб-планировщик с синхронизацией на телефон |

Не разобраны: российские аналоги (Яндекс Карты, 2GIS, OsmAnd, Mapy.cz), цены в рублях, доступность зарубежных сервисов в РФ.

## Сравнение функций
| Область | moto.tours | Calimoto / Kurviger |
|---|---|---|
| Базовый маршрут, точки, кольцо | Adequate | Strong |
| Извилистые дороги | Absent (нет в настройках, проверено 20.10.2026) | Strong |
| Избегание грунта / платных / магистралей | Absent (нет в настройках) | Strong (Kurviger) |
| Скорости, топливо, заправки | Strong | Weak |
| Бюджет поездки | Strong | Absent |
| Разбивка по дням | Strong | Adequate |
| Мото-POI | Strong | Adequate |
| Погода по дням пути, восход/закат | Adequate (погода по дням в отдельном блоке при заданной дате) | Weak |
| Экспорт/импорт GPX | Есть кнопка скачивания, формат не проверен | Strong |
| Шаринг ссылкой | Есть кнопка копирования, назначение не проверено | Adequate |
| Навигация, офлайн, трекинг | Absent | Strong |

## Выводы
- **Паритет:** GPX, шаринг, сохранение маршрутов, мобильная вёрстка.
- **Дифференциация:** извилистый режим, мото-логистика, бюджет, светлое время.
- **Отложить:** навигация, трекинг, соцсеть.
- **Следить:** релизы и цены Calimoto/Kurviger, российские аналоги.
