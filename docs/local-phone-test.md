# Проверка «Версты» на телефоне через свой компьютер

Дата: 2026-10-28. Вопрос владельца: «Мы сможем без сервера собрать приложение apk, чтобы я мог локально на телефоне всё протестировать?» (ответ в `docs/process/worklog.md`).
Коротко: отдельный сервер не нужен, им будет ваш компьютер. Телефон открывает сайт по Wi-Fi.

## Что нужно
- Компьютер с Linux, macOS или Windows (WSL2), Docker и Docker Compose; 8–16 ГБ памяти и 20–30 ГБ диска для одной области (оценка, не проверено).
- `osmium-tool` для слоя АЗС и жилья (`apt install osmium-tool` или `brew install osmium-tool`).
- Телефон в той же сети Wi-Fi.

## Шаги
```bash
git clone https://github.com/Artivio-owner/moto-route-planner.git
cd moto-route-planner/infra
cp .env.example .env
# В .env: DOMAIN=<адрес компьютера в сети, например 192.168.1.20>,
#         GRAPHHOPPER_MEMORY=4g, PHOTON_MEMORY=2g
REGIONS="ru/central-fed-district" BBOX="30,50,45,60" ./scripts/prepare-data.sh
docker compose --profile full up -d --build
docker compose logs -f graphhopper   # дождитесь «Started Server»: первая сборка графа и высот, минуты
```
Адрес компьютера в сети покажут `ip addr`, `ipconfig` или настройки Wi-Fi. Caddy отвечает только на адрес из `DOMAIN`, поэтому впишите туда именно его, а на телефоне откройте `https://192.168.1.20/` (ваш адрес).

## Что учесть
- Для IP-адреса Caddy выпускает собственный сертификат (по документации Caddy; в среде разработки не проверено): телефон покажет предупреждение. Для проверки его можно принять; установить сайт на главный экран как приложение (PWA) получится только с настоящим доменом и сертификатом.
- Регион небольшой: маршрут строится только по нему (центр России в примере). Другой регион: любой путь Geofabrik в `REGIONS` и его рамка в `BBOX` (запад, юг, восток, север).
- Первая сборка скачивает файлы высот (ADR-0016). Без интернета на компьютере уберите строки `graph.elevation.*` из `infra/graphhopper/config.yml`: профиль высоты просто не появится.
- Не проверено в среде разработки: скачивание данных и сборка на реальной выгрузке (источники закрыты её политикой сети).

## А APK?
APK сам по себе сервер не заменит: построение маршрута, поиск адресов, погода и тайлы работают на серверной части. Если нужен именно APK, его можно собирать в GitHub Actions с адресом сервера (вашего компьютера или будущего хостинга) в настройках: скажите, и я добавлю такую сборку.
