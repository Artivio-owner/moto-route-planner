# ADR-0002: Технический стек

- **Статус:** Предложено; маршрутизация GraphHopper 11 подтверждена функционально (S-01, 2026-10-26); ждёт S-02 и замеров памяти S-03
- **Дата:** 2026-10-20

## Контекст
Нужен стек для планировщика мотомаршрутов на русском языке с открытыми данными и без платных API в ядре.

## Решение (предложение)
TypeScript, React + Vite, MapLibre GL JS, Fastify, PostgreSQL/PostGIS, GraphHopper, Photon/Nominatim, Docker Compose. Подробности: [03-tech-stack.md](../03-tech-stack.md).

## Альтернативы
Valhalla или OSRM для маршрутизации; Python FastAPI на бэкенде; Leaflet на карте.

## Последствия
Один язык на фронте и бэке, независимость от платных карт. Нужен сервер с достаточной памятью под OSM по России. Решение финализируем после спайков.

## Результаты S-01 (2026-10-26)
GraphHopper 11.0: избегание грунта, пометки паромов и платных участков, режим «извилистые» работают на синтетической сети, проверка в CI. Память для России не измерена. Отчёт: `docs/spikes/s01-graphhopper.md`.

## Что используется в v0.1 (2026-10-26)
TypeScript, React 19 + Vite 8, MapLibre GL 6 + PMTiles (ADR-0015), Fastify 5, GraphHopper 11, Photon, pdf-lib (ADR-0014). PostgreSQL/PostGIS в v0.1 не нужен: маршруты не хранятся, POI появятся в v0.3.
