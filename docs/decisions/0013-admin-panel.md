# ADR-0013: Админка для владельца

- **Статус:** Принято: админка нужна (владелец, 2026-10-21). Способ реализации: предложен вариант C, ждёт подтверждения владельца. Заменяет ADR-0010.
- **Дата:** 2026-10-21

## Контекст
В ADR-0010 предлагалось обойтись без админки и менять настройки через PR. Владелец ответил: «Админка нужна». Через неё он будет менять курс доллара и цены (CFG-03) и значения по умолчанию: цены на топливо, жильё, еду, кофе, пресеты.
Аккаунтов у пользователей по-прежнему нет (ADR-0005): админка нужна только владельцу, это не личный кабинет.

## Варианты
| Вариант | Как работает | Плюсы | Минусы |
|---|---|---|---|
| **B. Своя админка** | Страница `/admin` со входом владельца, значения хранятся в БД, API отдаёт их сайту | Изменения применяются сразу; интерфейс полностью свой | Пароль, защита от подбора, резервные копии БД, больше кода; поверхность атаки на публичном сервере |
| **C. Админка поверх репозитория (Git-CMS)** | Страница `/admin` с формами; вход через GitHub; при сохранении редактор делает коммит в `data/*.json`, сайт пересобирается | Своих паролей и БД нет; вся история изменений в Git; проверка схемой в CI; откат одной кнопкой | Изменение видно после пересборки (минуты, не проверено); нужен аккаунт GitHub у владельца (есть); нужна настройка входа через GitHub OAuth под выбранный хостинг (не проверено) |

## Предложение
Вариант **C**: он даёт владельцу интерфейс с формами и сохраняет «конфигурацию как код». Если задержка на пересборку окажется неудобной или хостинг не позволит вход через GitHub, перейти на B. Конкретный редактор (открытые Git-CMS с лицензией MIT или похожей) выбираем в спайке ADM-01, лицензию проверяем там же.

## Решение
- Админка будет: она входит в выпуск v0.1, чтобы владелец мог задать цену топлива и курс до запуска.
- Настройки хранятся в `data/` со схемами валидации (CFG-01, CFG-02) при любом варианте, так что выбор B или C не меняет формат данных.
- Изменения из админки помечаются для пользователей как «ориентировочно» (`docs/14-trip-parameters-spec.md`, раздел 6).

## Последствия
- ADR-0010 заменён этим решением.
- Новые задачи: ADM-01 (спайк выбора редактора), ADM-02 (формы для цен, курса, пресетов, порогов), ADM-03 (доступ только владельцу).
- В варианте B понадобятся БД настроек и правило резервных копий; это отдельное решение.
