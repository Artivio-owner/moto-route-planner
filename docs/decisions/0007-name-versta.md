# ADR-0007: Название проекта «Верста»

- **Статус:** Принято (владелец, 2026-10-21)
- **Дата:** 2026-10-21

## Контекст
Были предложены три названия: «Вираж», «Верста», «Привал» (см. `docs/10-brand-and-design.md`).

## Решение
Проект называется **«Верста»** (латиницей Versta). Верста — старая русская мера расстояния; название связано с дорогой, надёжностью и путевым листом.

## Не проверено
- Свободные домены (в том числе `versta.*`).
- Товарный знак (ФИПС и международные базы).
- Совпадения с существующими сервисами: найдено туристическое приложение «7 Вёрст» (не мото); других проверок поиском не проводилось.

## Последствия
- Название заменяется в README, макетах и документах; имя репозитория `moto-route-planner` пока остаётся (переименование: отдельное решение, в GitHub ссылки на старое имя переадресуются).
- Дизайн-направление по-прежнему ждёт решения владельца (D-01).
