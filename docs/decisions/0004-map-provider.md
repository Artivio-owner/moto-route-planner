# ADR-0004: Провайдер карт и маршрутизации

- **Статус:** Принято предварительно: OSM-стек (владелец 2026-10-21, ответы 16–17); пробки не в MVP
- **Дата:** 2026-10-20

## Контекст
Конкурент строит конструктор на Яндекс Картах. Наше предложение (ADR-0002) опирается на OpenStreetMap, GraphHopper и свои тайлы. Для русскоязычной аудитории Яндекс даёт качественную карту, поиск адресов и пробки, но привязывает к его условиям использования.

## Варианты
A. Полностью открытый стек (OSM, GraphHopper, Photon, MapLibre).
B. Яндекс API для карты, геокодера и маршрутов.
C. Гибрид: Яндекс для карты и геокодера, свой движок для мотомаршрутов.

## Что нужно проверить до решения (не проверено)
- Условия Яндекс API для коммерческого проекта и лимиты бесплатного тарифа.
- Можно ли по условиям экспортировать маршрут в GPX и отображать его не на карте Яндекса.
- Умеет ли Яндекс-маршрутизация мотоциклетный профиль, извилистость и избегание грунта (по умолчанию нет).
- Качество русских адресов в Photon/Nominatim по сравнению с Яндексом (спайк S-02).

## Предварительная позиция
Вариант A: наши главные дифференциаторы (извилистость, избегание грунта, GPX) требуют контроля над маршрутизацией. Решение финализируем после спайков.

## Результаты проверки (2026-10-21)
- Условия бесплатного использования API Яндекс Карт: данные нельзя сохранять и изменять; запрещены скриншоты карт и статические карты, и это нельзя обойти даже коммерческой лицензией. Источник: https://yandex.ru/dev/commercial/doc/ru/
- Вывод: PDF путевой лист с картой (ядро продукта) нельзя делать на Яндекс Картах. Карта рисуется на тайлах OSM.
- Слой пробок Яндекса существует только внутри их карты. В MVP не делаем; бесплатных альтернатив не проверяли.
