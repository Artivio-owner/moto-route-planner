# ADR-0008: Лицензия кода

- **Статус:** Требует решения владельца
- **Дата:** 2026-10-21

## Контекст
Владелец хочет открытый проект для всех, но указал «без лицензии». В GitHub репозиторий без лицензии по умолчанию защищён авторским правом: код можно просматривать и форкать на платформе, но использовать и распространять нельзя без разрешения.

## Варианты
- MIT: максимально свободно, можно использовать в закрытых проектах.
- AGPL-3.0: производные веб-сервисы обязаны открывать код; защищает от закрытых клонов.
- Без лицензии: формально не открытый код.

## Рекомендация
MIT, если цель максимально простая открытость; AGPL-3.0, если хотите, чтобы чужие копии сервиса тоже оставались открытыми. Не юридическая консультация. Данные OSM остаются под ODbL независимо от лицензии кода.
