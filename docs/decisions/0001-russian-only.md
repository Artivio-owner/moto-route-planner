# ADR-0001: Только русская версия

- **Статус:** Принято
- **Дата:** 2026-10-20

## Контекст
Владелец продукта определил: нужна только русская версия.

## Решение
Интерфейс, документация и контент только на русском. Интернационализацию (i18n) не делаем.

## Альтернативы
Двуязычная версия: отложено, удорожает MVP и SEO.

## Последствия
Быстрее выход на рынок. Чтобы не закрыть дорогу, все строки интерфейса храним в одном месте, а не разбрасываем по компонентам.
