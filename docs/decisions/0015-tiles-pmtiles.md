# ADR-0015: Тайлы карты: PMTiles в схеме Protomaps, свой стиль

- **Статус:** Принято разработкой (2026-10-26); на реальных тайлах не проверено
- **Дата:** 2026-10-26

## Контекст
ADR-0004: карта на наших тайлах OSM, без Яндекса. Нужна подложка для сайта и снимков в PDF без отдельного тайл-сервера.

## Решение
- Векторные тайлы одним файлом PMTiles (`/tiles/region.pmtiles`), который отдаёт обычный веб-сервер по HTTP Range; клиент читает его через библиотеку `pmtiles` (BSD-3).
- Схема слоёв Protomaps (earth, water, landuse, landcover, roads, boundaries, places). Файл для России владелец получает командой `pmtiles extract` из ежедневной сборки Protomaps (инструкция: `docs/deploy.md`).
- Стиль свой, в палитре ADR-0009: `apps/web/public/map/style.json`. Подписи: Noto Sans (OFL), диапазоны латиницы и кириллицы лежат в `apps/web/public/map/glyphs/`.

## Альтернативы
- OpenMapTiles + свой тайл-сервер: больше сервисов в развёртывании.
- Внешний сервис тайлов (MapTiler и др.): платный и с лимитами, противоречит принципу «без платных API в ядре».

## Последствия
- Нет отдельного тайл-сервера; файл России весит гигабайты (не измерено).
- Не проверено: соответствие стиля реальным тайлам Protomaps (политика сети этой среды закрывает build.protomaps.com), наличие `name:ru` в тайлах.
- Подписи на других письменностях (грузинская, армянская) потребуют дополнительных диапазонов глифов (v0.2).
