# ADR-0014: PDF путевой лист собирается в браузере

- **Статус:** Принято разработкой (2026-10-26), спайк S-05; владелец может пересмотреть
- **Дата:** 2026-10-26

## Контекст
PDF путевой лист: ядро продукта (`docs/11-pdf-report-spec.md`). Нужны кириллица, карта на наших тайлах (ADR-0004), графики. Маршруты на сервере не хранятся (ADR-0005), бюджет на сервер не определён (O-01).

## Варианты (из спецификации 11)
| Вариант | Итог проверки |
|---|---|
| Сервер: headless-браузер печатает HTML в PDF | Работает, но нужен Chromium на сервере: память и процессор на каждый запрос, очередь |
| Сервер: библиотека PDF | Карта и графики на сервере сложнее, всё равно нужен рендер тайлов |
| **Клиент: сборка PDF в браузере** | Выбрано |

## Решение
PDF собирается в браузере пользователя библиотекой pdf-lib (MIT) со встроенным шрифтом Rubik (OFL, статические начертания Regular и Bold, собранные из вариативного файла Google Fonts). Карта: снимок MapLibre на наших тайлах вне экрана; если WebGL недоступен, рисуется векторная схема маршрута с ночёвками.

## Последствия
- Сервер не тратит ресурсы на PDF и не видит маршрут: совпадает с ADR-0005.
- Код PDF (около 1 МБ в сжатом виде с шрифтами и pdf-lib) загружается только по кнопке «Скачать PDF».
- Очень длинные маршруты рисуются с прореживанием линии (до 1500 отрезков в схеме).
- Проверено: тест собирает PDF в Node без WebGL; браузерный прогон собирает PDF со снимком карты; страницы отрисованы pdftoppm, кириллица корректна.
- Не проверено: слабые телефоны и маршруты на 30+ дней (время сборки и память браузера).
