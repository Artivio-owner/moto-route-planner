# ADR-0006: Весь мир, покрытие поэтапно

- **Статус:** Принято (владелец, 2026-10-21); уточнено 2026-10-21: v0.1 только Россия
- **Дата:** 2026-10-21

## Контекст
Цель: весь мир. Первоочередные регионы: Россия, Грузия, Турция, Европа, Казахстан.

## Решение
- Этап 1: Россия, Казахстан, Грузия, Турция. Внутри этапа: **v0.1 только Россия**, Казахстан, Грузия и Турция в v0.2 вместе с русскими названиями за рубежом (G-02) (владелец, ответ А5).
- Этап 2: Европа.
- Этап 3: остальной мир по запросу.
- Для каждого региона нужны: экстракт OSM, граф маршрутизации, геокодер, цена топлива по умолчанию и валюта.
- Интерфейс только на русском (ADR-0001); названия мест за рубежом показываем по-русски, если в OSM есть `name:ru`, иначе латиница.

## Последствия
- Память и диск растут с каждым регионом: спайки S-03 и G-01.
- Цена топлива 75 ₽/л справедлива только для России: нужны значения по странам (C-12).
- Маршрут через границы может включать пункты пропуска и визовые ограничения: вне MVP, но предупреждение «проверьте правила въезда» желательно.

## Реализация v0.2 (2026-10-28)
- Страна участка маршрута определяется по часовому поясу IANA (`packages/calc/src/countries.ts`): границы поясов в базе tz-lookup проведены по государственным границам. Отдельной базы границ и запросов к внешним сервисам не нужно. Пояса вне списка дают «страна не определена»: на таких участках предупреждения о границе нет, топливо считается по вашей цене.
- На границе показывается предупреждение «проверьте документы, страховку и правила въезда» (R-10, вопрос 9).
- Топливо считается по цене страны участка: Казахстан, Грузия и Турция в `data/fuel-prices.json`, в рублях (заглушки разработки, ждут владельца). Цена, изменённая пользователем, действует в России.
- Данные сервера для четырёх стран: `REGIONS="ru kz ge tr" infra/scripts/prepare-data.sh`. Поиск адресов за рубежом остаётся открытым (G-02).
- Не проверено: точность определения страны у самой границы, размеры и память графа для четырёх стран (G-01).
