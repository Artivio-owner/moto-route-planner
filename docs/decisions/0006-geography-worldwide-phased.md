# ADR-0006: Весь мир, покрытие поэтапно

- **Статус:** Принято (владелец, 2026-10-21); порядок этапов предложен
- **Дата:** 2026-10-21

## Контекст
Цель: весь мир. Первоочередные регионы: Россия, Грузия, Турция, Европа, Казахстан.

## Решение
- Этап 1: Россия, Казахстан, Грузия, Турция.
- Этап 2: Европа.
- Этап 3: остальной мир по запросу.
- Для каждого региона нужны: экстракт OSM, граф маршрутизации, геокодер, цена топлива по умолчанию и валюта.
- Интерфейс только на русском (ADR-0001); названия мест за рубежом показываем по-русски, если в OSM есть `name:ru`, иначе латиница.

## Последствия
- Память и диск растут с каждым регионом: спайки S-03 и G-01.
- Цена топлива 75 ₽/л справедлива только для России: нужны значения по странам (C-12).
- Маршрут через границы может включать пункты пропуска и визовые ограничения: вне MVP, но предупреждение «проверьте правила въезда» желательно.
