# Спайк S-01: GraphHopper и мото-профиль

Дата: 2026-10-26. Связано: ADR-0002, ADR-0004, задачи R-08, M-01, M-04. Решение владельца А1: спайк без своего сервера.

## Что проверяли
GraphHopper 11.0 (Apache 2.0) из Maven Central, Java 21. Конфигурация и модели: `infra/graphhopper/`.

| Профиль | Модели | Подготовка | Зачем |
|---|---|---|---|
| `moto` | `moto.json` + `avoid_unpaved.json` | CH (быстро) | По умолчанию, без грунта (А4) |
| `moto_unpaved` | `moto.json` | CH | Переключатель «можно по грунту» |
| `moto_curvy` | `moto.json` + `avoid_unpaved.json` + `curvy.json` | LM (гибко, медленнее) | Проба режима «извилистые» (M-01, P1) |

Модели свои: допуск по `car_access`, скорость не выше `car_average_speed`, грунт (`surface` = unpaved, gravel, dirt и др., `road_class` = track) с приоритетом 0,05; в «извилистом» прямые участки (`curvature` > 0,85) и магистрали получают меньший приоритет.

## Данные
Политика сети этой облачной среды закрывает download.geofabrik.de и другие источники выгрузок OSM, поэтому реальную Россию здесь не загрузить.
1. **Андорра** (тестовый файл из репозитория GraphHopper, данные 2013 г.): импорт и запуск прошли за секунды, маршруты строятся, ответ содержит классы дорог, покрытие, платность, паромы. Грунтовок в этом файле нет, для проверки моделей он не годится.
2. **Синтетическая сеть** (`infra/graphhopper/test/make_synthetic.py`): четыре сценария с известным ответом. Проверка `test/check_profiles.py` запускается в CI (задание «Мото-модели GraphHopper»).

## Результаты (синтетическая сеть)
| Сценарий | Результат |
|---|---|
| Гравийка 12,8 км против асфальтового объезда 35,7 км | `moto`: объезд; `moto_unpaved`: гравийка ✔ |
| Платная автомагистраль | `details.toll` = `all` ✔ (R-08: пометку делаем по этому полю) |
| Паром с `duration=00:40` | `details.road_environment` = `ferry`, время парома учтено ✔ |
| Прямая магистраль против серпантина | `moto`: прямая; `moto_curvy`: серпантин ✔ (M-01 реализуем этим способом) |

## Как API использует ответ
- Классы дорог GraphHopper → наши 4 класса: `motorway` → автомагистраль; `trunk` → магистраль; `primary`, `secondary` → региональная; остальные → местная (спецификация 14, раздел 2).
- Время считаем по скоростям пользователя (C-01), кроме паромов: для них время из GraphHopper (`details.time`).
- `ch.disable=true` нужен только для `moto_curvy`.

## Не проверено (нужен сервер владельца или открытый доступ к Geofabrik)
- Память, диск и время сборки графа для России, Казахстана, Грузии, Турции (S-03, G-01). Команда для замера:
  `java -Xmx<N>g -Ddw.graphhopper.datareader.file=russia-latest.osm.pbf -jar graphhopper-web-11.0.jar import config.yml`
- Качество тегов `surface` в России: при пустом `surface` (`missing`) грунтовая дорога может не распознаться. Нужен замер доли `missing` на выгрузке (вместе с S-04).
- Скорость ответа на маршруте Сочи — Владивосток.

## Вывод
GraphHopper закрывает все функции v0.1 (избегание грунта, пометки паромов и платных дорог) и даёт рабочий путь к режиму «извилистые». ADR-0002 по маршрутизации подтверждён функционально; требования к серверу остаются открытыми.

## Дополнение 2026-10-28: избегание платных дорог и магистралей (M-02)
- Переключатели «Избегать платных дорог» и «Избегать автомагистралей» передают в запрос свою модель: `toll == ALL` и `road_class == MOTORWAY` с приоритетом ×0,1. Это «избегать», а не «запретить»: если объезда нет, маршрут проходит по такой дороге и помечается в путевом листе.
- Запросы со своей моделью идут без CH, поэтому для `moto` и `moto_unpaved` добавлена LM-подготовка (`profiles_lm`).
- Проверено на синтетической сети (сценарий 5: бесплатный объезд платной магистрали) в `check_profiles.py` и сквозной проверке API в CI.
- Не проверено: память и время подготовки LM для России (S-03), скорость таких запросов на длинных маршрутах.
