# Админка «Версты»: инструкция для владельца

Решение: ADR-0013, вариант C. Редактор: Sveltia CMS (MIT). Адрес: `https://<ваш-домен>/admin/`.

## Что можно менять
| Раздел | Файл | Что внутри |
|---|---|---|
| Цены топлива | `data/fuel-prices.json` | Цены АИ-92, 95, 100 по странам, дата обновления |
| Курс доллара | `data/exchange-rate.json` | Рублей за доллар |
| Пресеты мотоцикла | `data/moto-presets.json` | Бак, расход, скорости, дневные лимиты для «Новичок», «Чопперист», «Турэндуро» |
| Значения по умолчанию | `data/trip-defaults.json` | Пресет, людей и мотоциклов, валюта, грунт, остановки, история |
| Страны покрытия | `data/countries.json` | Страны и версия, с которой они доступны |
| Контакты и ссылки | `data/site.json` | E-mail, GitHub, ссылка «Сообщить об ошибке», «Поддержать разработчика»: текст кнопки, ссылка, QR-код |

Пользователи видят все цены и курс с пометкой «ориентировочно».

## Как войти (один раз)
1. На GitHub: Settings → Developer settings → Personal access tokens → **Fine-grained tokens** → Generate new token.
2. Repository access: только `Artivio-owner/moto-route-planner`. Permissions: **Contents: Read and write**. Срок действия: на ваш выбор (например, 1 год).
3. Откройте `/admin/`, нажмите «Войти с помощью токена доступа» и вставьте токен. Токен хранится только в вашем браузере.

Вход работает только у тех, у кого есть право записи в репозиторий: посторонний не сможет ничего изменить (ADM-03). Токен никому не передавайте и не записывайте в репозиторий.

## Как меняются данные
1. Правите поле, нажимаете «Сохранить».
2. Админка делает коммит в ветку `main` с сообщением `chore(data): ... через админку`. История всех правок видна в GitHub, любую правку можно откатить.
3. CI проверяет файл схемой (`pnpm validate:data`). Сборка сайта тоже проверяет данные и не соберётся с ошибкой, поэтому неверное значение не попадёт на сайт.
4. Сайт обновится после пересборки и выкладки (как именно, зависит от хостинга: `docs/deploy.md`).

## Если `main` защищена и коммит не проходит
Если в правилах ветки включено «изменения только через Pull Request», админка не сможет сохранить. Варианты:
- разрешить себе обход правила (Settings → Rules → ваш набор правил → Bypass list: вы как администратор);
- либо поменять в `apps/web/public/admin/config.yml` `branch: main` на `branch: content` и вливать ветку `content` в `main` через PR (Claude Code может это делать).

## Ограничения
- Перевод интерфейса и шрифты админки подгружаются с unpkg.com и cdn.jsdelivr.net. Без доступа к ним интерфейс будет на английском, но работать будет.
- Новую страну с ценами топлива нужно добавить и в `countries.json`, и полем в форме цен (форма описана в `apps/web/public/admin/config.yml`): это делает разработка.

## «Поддержать разработчика»
В разделе «Контакты и ссылки» укажите ссылку на страницу доната (начинается с https://) и загрузите QR-код. Пока ссылка пустая, блок нигде не показывается. QR-код лучше загружать в PNG или JPG: в PDF встраиваются только они; если картинки нет или она в другом формате, QR-код соберётся из ссылки автоматически. Картинки хранятся в `apps/web/public/media/`.
