# Правила работы в этом репозитории (для Claude Code)

Проект «Верста»: русскоязычный бесплатный сервис планирования мотопутешествий (название: ADR-0007; лицензия MIT: ADR-0008). Владелец работает с Claude Code, **всё обсуждение и решения должны быть детально записаны в репозитории**.

## Обязательно в каждой сессии
1. В начале прочитать: `docs/process/worklog.md`, `BACKLOG.md`, `docs/decisions/`, `docs/09-owner-answers-2026-10-21.md`.
2. Перед работой назвать, какую задачу из `BACKLOG.md` делаем.
3. В конце: обновить `BACKLOG.md` (статусы), дописать запись в `docs/process/worklog.md`, оформить ADR на любое трудно обратимое решение.
4. Все обсуждения с владельцем фиксировать: что спросили, что ответили, что решили, какие вопросы остались.

## Язык и стиль
- Интерфейс, документация, коммиты (описание), Issues: на русском.
- Коммиты в стиле Conventional Commits (`feat:`, `fix:`, `docs:`, `chore:`).
- Ветки `feat/<issue>-кратко`, PR по шаблону, `main` защищена. PR вливает Claude Code (разрешение владельца, 2026-10-21); ему же разрешено создавать метки и Issues.

## Ключевые решения (не нарушать без нового ADR)
- Только русская версия (ADR-0001). Весь мир, регионы поэтапно (ADR-0006).
- Оригинальная реализация, ничего не копируем с moto.tours (ADR-0003).
- OSM-стек, карта в PDF на наших тайлах, не на Яндексе (ADR-0004).
- Нет аккаунтов, нет серверного хранения маршрутов, шаринг через ссылку с состоянием в адресе, история 30 дней в браузере (ADR-0005).
- Дизайн: вариант 2 «бумажная карта», шрифт Rubik, скругления 18/12 px (ADR-0009, `docs/design/design-system.md`).
- Группа: людей 1/2 и мотоциклов 1/2, один профиль на все мотоциклы; без ограничений на размер маршрута (ADR-0011); время местное по часовым поясам; цены помечены «ориентировочно» (`docs/14-trip-parameters-spec.md`).
- Выпуск версиями v0.1–v0.3 (ADR-0012); v0.1 только Россия, грунт избегаем, валюты ₽ и $ (ADR-0006, ADR-0012).
- Контакт: net.buzz@mail.ru. Юридические тексты по шаблону. Слоя «мотобратья» нет.
- Админка для владельца нужна (ADR-0013, заменяет ADR-0010): настройки в `data/` со схемами, редактируются через админку; вариант C: Git-CMS поверх репозитория, вход через GitHub (владелец, 2026-10-21).
- Ядро продукта: PDF путевой лист (`docs/11-pdf-report-spec.md`).
- Бюджет: жильё за номер, цены редактируемые, кофе от числа заправок (`docs/07-budget-spec.md`).
- Разбивка по дням: `docs/08-day-split-spec.md`.

## Что нельзя
- Копировать код, тексты, дизайн, данные других сервисов.
- Подключать платные API и внешние трекеры без решения владельца.
- Записывать в репозиторий секреты и ключи.
- Утверждать непроверенное: помечать «не проверено» и записывать в открытые вопросы.
