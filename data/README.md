# Настройки сервиса

Файлы читаются сайтом и API при сборке. Владелец меняет их через админку (ADR-0013), разработка через PR. Каждый файл проверяется схемой из `schemas/` в CI: `pnpm validate:data`.

| Файл | Что внутри |
|---|---|
| `fuel-prices.json` | Цены топлива по странам и маркам, ₽ за литр |
| `exchange-rate.json` | Курс: рублей за доллар |
| `moto-presets.json` | Пресеты профиля мотоцикла (спецификация 14, раздел 2) |
| `trip-defaults.json` | Значения по умолчанию: остановки, лимиты, история, валюта |
| `countries.json` | Страны покрытия и версия, с которой они доступны |
| `site.json` | Контакт и ссылки для подвала и PDF |
| `budget-defaults.json` | Бюджет: цены жилья за номер, еды, кофе, резерв |

Все цены и курс показываются пользователю с пометкой «ориентировочно» (спецификация 14, раздел 6).
