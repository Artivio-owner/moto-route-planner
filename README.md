# Moto Route Planner

Русскоязычный веб-сервис для планирования мотопутешествий: маршрут, топливо, бюджет, ночёвки по дням, погода и светлое время суток в одном потоке.

> Статус: **идёт проектирование (этап 0)**. Код ещё не написан.
> Рабочее название репозитория: `moto-route-planner` (можно заменить).

## Зачем
Существующие мотопланировщики сильны в поиске извилистых дорог, но слабы в логистике всей поездки. Мы делаем планировщик «поездки целиком» и закрываем рыночный минимум: экспорт GPX, шаринг ссылкой, режим «извилистые дороги».
Подробнее: [docs/00-vision.md](docs/00-vision.md).
